# راهنمای سریع (فارسی)

این مخزن برای هر مدار QCA که در QCADesigner کشیده‌اید، دیتاست «جابه‌جایی سلول خروجی ← اتلاف انرژی» می‌سازد.
همه‌چیز داخل Docker اجرا می‌شود: **نیازی به کامپایل، وصله (patch) یا نصب QCADesigner-E نیست.** فقط دستورهای زیر را کپی کنید.

## ۱. نصب Docker و Git (یک بار)

* **اوبونتو:**

  ```bash
  sudo apt-get install -y docker.io git
  sudo usermod -aG docker $USER
  ```

  بعد از این دو دستور یک بار از سیستم خارج شوید و دوباره وارد شوید (یا ماشین مجازی را ری‌استارت کنید).
* **ویندوز یا مک:** برنامهٔ Docker Desktop را نصب و اجرا کنید (در ویندوز Git for Windows را هم نصب کنید و دستورها را در Git Bash بزنید).

## ۲. دریافت مخزن و اجرای نمونهٔ جمع‌کنندهٔ کامل (Full Adder)

```bash
git clone https://github.com/oom-debugger/qca-scdd-energy-dataset.git
cd qca-scdd-energy-dataset
./simulate.sh layouts/FULLADDER.qca
```

* بار اول چند دقیقه طول می‌کشد تا شبیه‌ساز داخل Docker ساخته شود؛ بارهای بعد فوری شروع می‌شود.
* برای هر سلول خروجی مدار (در این مثال `Sum` و `Cout`) ۲۵۸ نسخهٔ جابه‌جاشده ساخته و شبیه‌سازی می‌شود.
* نتیجه در پوشهٔ `data/` است: `data/spe_FULLADDER_Sum.csv` و `data/spe_FULLADDER_Cout.csv`.
  هر سطر یک جابه‌جایی است (جهت، فاصله، قطبش مثبت و منفی خروجی، انرژی کل، انرژی متوسط هر سیکل). این فایل‌ها را می‌توانید مستقیم در Excel باز کنید.
* در ستون `status` باید همهٔ سطرها `ok` باشند. اگر خطایی رخ دهد، اسکریپت در همان اولین شبیه‌سازی متوقف می‌شود و علت را می‌نویسد؛ به جای ۲۵۹ سطر خالی.
* اگر اجرا قطع شد، همان دستور را دوباره بزنید: سطرهای انجام‌شده نگه داشته می‌شوند و ادامه می‌دهد.

## ۳. مدار خودتان

1. مدار را در QCADesigner بکشید. سلول(های) خروجی را از نوع **Output** بگذارید و به آن‌ها **برچسب (label)** بدهید (مثلاً `Z` یا `Sum`).
2. فایل `.qca` را در پوشهٔ `layouts/` این مخزن کپی کنید.
3. اجرا کنید:

   ```bash
   ./simulate.sh layouts/نام_فایل.qca            # همهٔ سلول‌های خروجی
   ./simulate.sh layouts/نام_فایل.qca Sum        # فقط سلول خروجی با برچسب Sum
   ```

   نتیجه: `data/spe_نام_فایل_برچسب.csv`.

فاصله‌های جابه‌جایی پیش‌فرض: شمال/جنوب ۰٫۱ تا ۴٫۶ نانومتر (گام ۰٫۱)، شرق ۰٫۱ تا ۳٫۴ (گام ۰٫۱)، غرب ۰٫۰۱ تا ۱٫۳۲ (گام ۰٫۰۱). برای تغییر آن‌ها می‌توان `qca_scdd_dataset.py` را مستقیم با گزینه‌های `--north/--south/--east/--west` اجرا کرد (توضیح در `README.md`).

## اگر خطا دیدید

| پیام | معنی و راه حل |
|---|---|
| `Docker is not installed` / `not running` | Docker نصب یا اجرا نیست؛ بند ۱ را انجام دهید. در اوبونتو بعد از `usermod` باید خارج و دوباره وارد شوید. |
| `has no OUTPUT cell` | در فایل `.qca` هیچ سلولی از نوع Output نیست؛ در QCADesigner سلول خروجی را Output کنید و ذخیره کنید. |
| `no OUTPUT cell called '...'` | برچسبی که نوشته‌اید وجود ندارد؛ فهرست سلول‌ها همان‌جا چاپ می‌شود. |
| `Failed to open simulation options file !` | یعنی شبیه‌سازِ وصله‌نشده اجرا شده است. با `./simulate.sh` این اتفاق نمی‌افتد؛ QCADesigner-E را خودتان کامپایل یا وصله نکنید. |

هیچ‌وقت لازم نیست `autogen.sh`، `configure`، `make` یا `git apply` را خودتان اجرا کنید؛ همهٔ این‌ها داخل Docker و به‌صورت خودکار انجام می‌شود.
